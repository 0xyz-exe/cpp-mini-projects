# Tic-Tac-Toe

Two-player console tic-tac-toe game.

## Features
- Two-player local play
- Board rendering
- Turn validation
- Win/draw detection
- Position input (1-9)

## Build & Run
```bash
cmake --build build --target tictactoe
./build/projects/10-tic-tac-toe/tictactoe
```

## Test
```bash
./build/projects/10-tic-tac-toe/tictactoe_test
```

## Concepts
- Class-based game logic
- Array/std::array
- Game state management
- Win condition checking
- Input validation
