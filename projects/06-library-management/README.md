# Library Management System

Track books and borrowing status.

## Features
- Book catalog with ISBN/title/author
- Search by title or author
- Borrow/return operations
- Availability tracking
- Member records
- Persistent storage

## Build & Run
```bash
cmake --build build --target library
./build/projects/06-library-management/library
```

## Test
```bash
./build/projects/06-library-management/library_test
```

## Concepts
- Multiple related structs
- Search algorithms
- State management
- Business logic validation
