# Student Grade Manager

Manage student records and calculate statistics.

## Features
- Add, edit, search, remove students
- Store ID and grades
- Calculate averages
- Sort by grade
- CSV export
- Input validation

## Build & Run
```bash
cmake --build build --target student_manager
./build/projects/04-student-grade-manager/student_manager
```

## Test
```bash
./build/projects/04-student-grade-manager/student_test
```

## Concepts
- Struct with multiple fields
- Vector operations
- Algorithm library (sort, find_if)
- CSV formatting
