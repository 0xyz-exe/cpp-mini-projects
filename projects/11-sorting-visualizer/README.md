# Sorting Algorithm Visualizer

Step-by-step visualization of sorting algorithms.

## Features
- Bubble Sort
- Insertion Sort
- Merge Sort
- std::sort comparison
- Console visualization
- Basic timing (includes visualization overhead)

## Build & Run
```bash
cmake --build build --target sorting_viz
./build/projects/11-sorting-visualizer/sorting_viz
```

## Test
```bash
./build/projects/11-sorting-visualizer/sorting_test
```

## Concepts
- Algorithm implementation
- Recursion (merge sort)
- std::chrono timing
- Comparison of algorithms
